# AtlasOS + Vitae — Master Brief for Codex

## Objective
Build the production-quality frontend foundation for AtlasOS + Vitae based on the prototype already created in Claude.

This is not a generic healthcare dashboard.
This is a real-time donor and transplant operations command platform designed to replace legacy systems such as iTransplant.

## Product framing
- AtlasOS = healthcare coordination operating system
- Vitae = donor and transplant coordination application
- Athena = AI-powered intelligence layer embedded into workflows

## What this system is
A real-time command center for:
- donor intake
- case triage
- donor case management
- workflow progression
- allocation visibility
- transport and scheduling coordination
- reporting and operational intelligence

## What this system is not
- a conventional EHR
- a static record-entry system
- a form-heavy admin portal
- a generic SaaS template

## Build goal
Codex should transform the prototype into a clean frontend architecture that:
- preserves the high-end visual direction
- creates a reusable design system
- supports all major application surfaces
- is ready for deeper engineering after the frontend foundation is stable

## Non-negotiable product surfaces
These must exist and feel real:
- Dashboard
- Case Board
- Donor Intake
- Case Detail View
- Workflow Aggregate View
- Matching
- Scheduling
- Reports
- Athena global context panel
- Athena case context panel

## Non-negotiable UX principles
- real-time feel
- urgency visibility
- minimal friction
- command-system orientation
- premium modern product quality
- system completeness

## Build constraint
Do not optimize one screen at the expense of the system.
Depth is important, but the app must remain complete and demoable end to end.

## Implementation intent
Codex should create a modular frontend codebase with:
- reusable layout shell
- reusable cards, panels, badges, timeline items, workflow steps
- centralized sample data
- app-level state
- room for future API integration

## Immediate build target
Build the first real frontend version with:
- app shell
- routing / screen switching
- shared design tokens
- seeded case data
- interactive workflow state
- Athena insight generation
- cohesive reports / matching / scheduling surfaces

## Quality bar
The result should feel like:
- elite modern SaaS
- mission control
- operational software for high-stakes environments

A reviewer should think:
"This is dramatically ahead of legacy transplant systems."
