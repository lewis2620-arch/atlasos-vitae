# Product Context

## Problem
Legacy donor and transplant coordination software is operationally entrenched but often fragmented, rigid, and poor at real-time coordination.

## Opportunity
AtlasOS + Vitae wins by combining:
- command center UX
- workflow-native operations
- case intelligence
- auditability
- modern frontend architecture
- future AI-assisted coordination

## Primary user groups
- donor coordinators
- allocation coordinators
- clinical operations leads
- supervisors / directors
- transport/logistics roles
- transplant center collaborators

## Primary jobs to be done
1. Receive and triage new donor cases fast
2. Move cases cleanly through workflow stages
3. Surface urgent actions early
4. Coordinate across teams and time windows
5. Maintain a trusted view of status and risk
6. Prepare the system for future automation and intelligence

## Product wedge
The wedge is not "better forms."
The wedge is:
- real-time coordination
- better workflow visibility
- Athena intelligence layer
- clean operational UX
- future-ready system architecture

## Demo narrative
The demo should prove:
- the system is complete
- the system feels modern
- the system handles donor workflow cleanly
- the system can plausibly replace legacy tooling
