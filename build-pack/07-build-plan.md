# Build Plan

## Phase 1 — Frontend Foundation
Goal:
Create the first stable production-style frontend foundation from the prototype.

### Deliverables
- app shell
- shared theme
- navigation
- central state
- seeded data
- all major screens rendered
- interactive workflow progression
- Athena insight generation

## Phase 2 — Surface Completion
Goal:
Ensure all top-level modules feel complete enough for demo and design validation.

### Deliverables
- robust Dashboard
- full Case Board
- strong Case Detail
- aggregate Workflow view
- Matching
- Scheduling
- Reports

## Phase 3 — Interaction Quality
Goal:
Increase realism and polish.

### Deliverables
- richer transitions
- better urgency states
- better status progression
- board-level actions
- stronger timeline interactions

## Phase 4 — Demo Flow
Goal:
Create an end-to-end narrative.

### Deliverables
- intake to board to case progression
- Athena insights along the way
- updated reporting after actions
- believable scheduling / matching context

## Future phases
Later, not now:
- drag and drop
- notifications center
- backend APIs
- auth
- persistence
- real AI services
- real interoperability
